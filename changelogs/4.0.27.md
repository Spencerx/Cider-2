# Cider 4.0.27

The miniplayer is the main event. It can take a few different layouts, including a Winamp window, and an album that is not out yet tells you how long you have to wait.

## Miniplayer

Open the miniplayer and choose a layout from Visual settings, or from the menu inside the miniplayer itself.

- **Cider Square** and **Cider Compact** are the current Cider windows.
- **Aqua**, **Aqua (alt.)**, **Aluminum**, **Unified**, and **Minimal** follow the old player windows those names come from. Lyrics and the queue open in the same window, and the window grows to fit them.
- **Winamp (1998)** is the classic window: transport, playlist, and windowshade. The playlist can be resized. The deck stays a fixed height.
- Skins drawn on a fixed pixel grid stay sharp when display scaling is not 100%.

## Albums that are not out yet

- An unreleased album shows a live countdown on the album page, in days, hours, minutes, and seconds. Click it to see the release date.
- The header carries an **Upcoming Album** badge.
- When the release time arrives, the countdown switches to Available now.

## New Shell Animations
- Various elements in the shell now have smoother and more visually appealing animations, improving the overall user experience.

## Scrobbling

4.0.24 started sending every play to every service you had switched on. Two of those services were refusing the plays, and Cider was treating the refusal as a success.

- **Libre.fm** reads scrobbles from the request body. The parameters were being sent on the query string, so every submission came back invalid and nothing was recorded. Plays go through now.
- **Maloja** does not accept an API key as a session. Cider now exchanges the key for a session, and if the server forgets that session it signs in again and retries once.
- A play that any connected service accepts is confirmed. A warning stays on the services that refused it, instead of hiding the confirmation for the ones that worked.
- A refused sign-in is reported, and the settings row stops saying it is waiting on the browser.

## Smaller things

- Listen Now hero artwork picks up the same light rim the rest of the artwork grid uses.
- Player and navigation buttons have a new press animation.
- Two visual settings that said Force now say Use: multiplatform window controls, and rounded viewport.
- The Connectivity page no longer shows VR overlay switches that did not control anything.
